# Qwen Code

פותחים את Open-Qwen-Code.bat. קובץ ההפעלה הישן, Open-Qwen-Agent.bat, ממשיך לעבוד.
זה האגנט המקומי עם אותו Qwen3.8 והגדרות CPU/GPU וניקוי הזיכרון הקיימות.

## השלמת פקודות

הקלד `/` כדי לראות פקודות, או התחל פקודה כגון `/mo` ולחץ Tab.
Tab וחצים בוחרים הצעה; Enter שולח את הפקודה שבחרת. Shift+Tab חוזר להצעה הקודמת.
גם `/mode`, `/git`, `/resume`, `/undo` ונתיבי תיקיות אחרי `/cd` או `/project` מקבלים השלמות.
תיקיות עם רווחים מקבלות מרכאות אוטומטית. ההצעות מתעדכנות לפי הפרויקט והשיחה הנוכחיים.

כשהרשימה סגורה, ↑ ו-↓ נעים בהיסטוריית ההודעות. → מקבל הצעת המשך מההיסטוריה.
היסטוריית הקלט נשמרת מקומית ב-state/input-history.txt, גם אחרי סגירת החלון.
ההשלמה פועלת בחלון האינטראקטיבי; היא אינה מבצעת פקודות ואינה פונה למודל.
ספריות prompt_toolkit, wcwidth ו-python-bidi נמצאות ב-vendor ליד האגנט; אין צורך בהתקנה גלובלית.
העברית מוצגת בכיוון תקין בהקלדה, בהשלמות, בהודעות ובתשובות המודל בחלון Windows.
המרת הכיוון נעשית לתצוגה בלבד: הפקודות, הנתיבים, השיחות והקלט למודל נשארים בסדר המקורי.

## התחלה

בחר תיקיית פרויקט בחלון:

    /cd "C:\Users\nagor\Downloads\my-project"

כתוב בקשה רגילה:

    חפש את התקלה בקוד, תקן אותה והריץ את הבדיקות.

האגנט יכול לחפש טקסט, לקרוא קבצים לפי שורות, ליצור קבצים, לערוך טקסט קיים, לנהל משימות ולהריץ פקודות PowerShell אחרי אישור.
מופיעים השלבים, תוצאות הכלים והשינויים לפני שמירת קוד. ברירת המחדל היא תיקיית Downloads; בהפעלות הבאות נשמרת תיקיית הפרויקט האחרונה.

## עריכות, תכנון והרשאות

    /mode normal
    /mode acceptEdits
    /plan בדוק איך להוסיף שמירת משתמשים
    /mode normal

normal מבקש אישור לפני שינוי קובץ קיים. יצירת קובץ חדש בתיקיית הפרויקט מותרת.
acceptEdits מאפשר עריכות קבצים בפרויקט בלי אישור נפרד לכל עריכה; פקודות שהמודל בוחר עדיין דורשות אישור.
plan מאפשר קריאה, חיפוש וניהול רשימת משימות; הוא חוסם עריכות והרצת פקודות גם אם המודל מבקש אותן.
מצב ההרשאות מתחיל ב-normal בהפעלה רגילה; המשך שיחה אינו מפעיל אוטומטית הרשאות רחבות מהשיחה הקודמת.

כלי הקבצים מוגבלים לתיקיית הפרויקט שבחרת, אחרי פתרון קישורים. תיקיית האגנט והמצב שלו מוגנים.
פקודות Shell מאושרות רצות בהרשאות המשתמש הרגילות; תיקיית הפרויקט היא תיקיית העבודה, ולא sandbox של מערכת ההפעלה.

## שינויים וביטול

    /diff
    /checkpoints
    /undo

כל יצירה ועריכה ישירה שומרת checkpoint. העריכה מחייבת התאמה אחת מדויקת, ושומרת BOM וסיומות CRLF של קובץ קיים.
undo מבטל עריכת קובץ אחת; אפשר לתת מזהה מ-checkpoints. אם הקובץ השתנה מאז העריכה, השחזור מסרב לדרוס את השינוי.
הגיבויים נמצאים בתוך state/checkpoints ליד האגנט. undo אינו מבטל פעולות של PowerShell או שינויי קבצים שבוצעו דרך פקודה.
Ctrl+C עוצר בקשה; כלים שכבר בוצעו נשארים מתועדים.

## שיחות וזיכרון פרויקט

    /sessions
    /resume
    /resume מזהה-שיחה
    /new
    /compact
    /remember השתמש ב-unittest והחזר תשובות בעברית
    /memory
    /context

השיחות נשמרות מקומית בתוך state/sessions, כולל בקשות, תשובות ותוצאות כלים.
resume בלי מזהה ממשיך את השיחה האחרונה בפרויקט. השיחות והמשימות זמינות גם אחרי סגירת החלון.
remember שומר הערה מפורשת לפרויקט; הוא אינו משנה את זיכרונות Codex.
AGENTS.md ו-CLAUDE.md שבשורש הפרויקט נטענים כהנחיות פרויקט, תחת הרשאות הכלים ובקשת המשתמש.
init יוצר AGENTS.md בסיסי אם אינו קיים; אינו מחליף קובץ קיים.

חלון המודל נשאר 2048 טוקנים. ההיסטוריה נשמרת בדיסק, ובכל קריאה המודל מקבל הקשר שנכנס לחלון הזה.
האגנט סופר את הטוקנים בעזרת התבנית והטוקנייזר של שרת Qwen, ושומר מקום לעד 512 טוקנים של תשובה.
הוא מצמצם סיכומי שיחה, קבוצות כלים קודמות וקטעי פלט לפי הצורך; התמליל השמור נשאר מלא.
compact יוצר סיכום מקומי קצר של העבודה האחרונה. הוא אינו סיכום מלא של כל השיחות ואינו מוסיף ידע למודל.
בקשה שעדיין גדולה מדי מחזירה שגיאה ברורה, במקום לשלוח אותה כשהיא חורגת מהחלון.

## בדיקות ו-Git

    /tasks
    /run python main.py
    /test python -m unittest discover -s tests
    /git status
    /git diff
    /git staged
    /git log
    /git branch

run ו-test מריצים את הפקודה שאתה מקליד במפורש, בלי אישור חוזר.
המודל אינו יכול להפעיל את פקודות ה-slash האלה; פקודות שהוא בוחר עוברות דרך run_powershell ודורשות אישור.
Git מציג מצב, diff, staged, היסטוריה וענפים. פעולות שינוי של Git אפשר להריץ במפורש דרך run או דרך כלי PowerShell מאושר.
לפקודות יש timeout של 120 שניות ופלט מוגבל. תהליך הפקודה וילדיו נמצאים ב-Windows Job נפרד ונסגרים בסיום או בעצירה.

## הפעלה מתיקייה או מתסריט

    Open-Qwen-Code.bat "C:\path\to\project" -Mode acceptEdits
    Open-Qwen-Code.bat "C:\path\to\project" -Continue

אפשר גם להפעיל ישירות את Qwen-Agent.py עם:

    --project "C:\path\to\project" --task "Create hello.py"
    --resume מזהה-שיחה
    --mode plan
    --report "C:\path\to\report.json"

במצב לא אינטראקטיבי אין אישור אוטומטי לפקודות. acceptEdits ניתן במפורש כדי לאפשר עריכות בפרויקט.

## אימות

20 בדיקות עברו: חיפוש, דפדוף שורות, שמירת שיחות, התאוששות מבקשה שנקטעה, משימות,
תכנון והרשאות, קישורים קשיחים, גיבוי ושחזור, שימור קידוד וסיומות שורות,
שינוי ידני בזמן אישור, timeout וסגירת תהליכי ילדים.
גם בדיקות מנגנון הזיכרון וה-stream הקודם עברו.

בדיקה עם Qwen האמיתי: האגנט קרא פונקציית multiply שהשתמשה בחיבור,
תיקן אותה לכפל עם edit_file, והריץ python main.py בהצלחה עם פלט 391.
פקודת הבדיקה היחידה אושרה על ידי תסריט הבדיקה; אין שינוי במדיניות ההרשאות הרגילה.
המשך אותה שיחה במצב plan קרא את הקוד והציע תוכנית בלי לשנות אותו.
undo שיחזר את הקובץ המקורי, ולאחר החזרת התיקון הבדיקה עברה שוב.
נמדדו 61.484 שניות לבקשת התיקון ו-60.234 שניות לבקשת התכנון; אלה בדיקות תפקוד, לא השוואת מהירות.
RAM הגיע לכל היותר ל-77.31% במדגמי הבדיקה. תקרת העצירה של 88% לא הופעלה.
נתונים מלאים: qwen-coding-verification.json.
